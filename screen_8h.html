Detailed Description

The screen layer: what every screen outside the round needs.

A screen is one function xxxRun(): compose with the display off, screenShow(), loop on screenFrame() + screenPressed(), screenClose(). The layer owns what they share, so no screen repeats it: the VBlank wait, the VRAM queue's flush, the fades, the pad's edges, and the pump, the one function the game wants run on every image whatever the screen is doing (its sound driver, its counters).
