Detailed Description

Mode 7 perspective with an HDMA split screen (F-Zero style).

Creates an F-Zero-style pseudo-3D ground plane by combining two BG modes on one screen. HDMA changes registers between scanlines: the top 96 lines show a sky in Mode 1 (BG2), the lines below a Mode 7 ground whose scale changes on every line, so that distant rows are compressed. Four HDMA channels share the work: one writes BGMODE at the split line, one the main screen layers (BG2 for the sky, BG1 for the ground), and two write M7A and M7D on every ground line.

This is the first step: the two diagonal terms of the matrix give depth without rotation. mode7/perspective_rotate drives all four terms per line and turns the world.

Based on PVSnesLib's Mode7Perspective (mills32 / alekmaul).

SNES Concepts
  • Mid-frame BG mode switching via HDMA (Mode 1 sky + Mode 7 ground)
  • Per-scanline M7A/M7D writes (HDMA repeat mode) for the perspective
  • HDMA-driven main screen layer switching
  • HDMA tables set up once: the hardware restarts each one every frame
  • Mode 7 scroll and center written in VBlank
What to Observe
  • The screen is split: a flat sky image on top and a perspective ground below
  • Press D-pad to scroll the ground plane in any direction
  • Distant ground rows appear more compressed (perspective foreshortening)
Modules Used
console, dma, background, sprite, input, mode7, hdma

◆ setCamera()

void setCamera ( void )
static

Place the camera: Mode 7 scroll and center, and the sky's scroll.

mode7SetScroll() and mode7SetCenter() write the registers at once, so this runs in VBlank or force blank. The sky follows the ground horizontally (bgSetScroll, written by the NMI handler).
