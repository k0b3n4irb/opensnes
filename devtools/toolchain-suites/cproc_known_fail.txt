# expected outputs written for the host ABI. The fork targets w65816 with
# `int` = 2 bytes, `long` = 4, and sections C const data into ".rodata",
# so the expected files cannot match. Every entry below is one of those
# facets (2026-09-13 audit of all 107: 104 IL diffs from type sizes /
# struct layout / the rodata section line, 3 front-end errors that are the
# 16-bit int itself — bit-field width, a `sizeof(enum)` static assert):
# none is a crash and none is a wrong-code bug.
#
# Ratchet semantics (devtools/toolchain_suites.py):
#   - a test NOT listed here that fails  → regression, the run fails;
#   - a test listed here that passes     → XPASS, the run fails: remove
#     it from this list (the fork got closer to upstream);
#   - listed and failing                 → expected.
