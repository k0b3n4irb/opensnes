@defgroup examples Examples
@brief Every OpenSNES example program, with annotated source code.

Each example's `main.c` carries `@par SNES Concepts` (the hardware features
it uses), `@par What to Observe` (what to look for when it runs) and
`@par Modules Used` (the library modules it links). The files below are
those sources; for the examples by topic, with their READMEs and
screenshots, see @ref examples_by_category.
