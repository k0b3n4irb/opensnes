# doxygen-awesome-css (copied files)

The documentation theme, by jothepro: <https://github.com/jothepro/doxygen-awesome-css>,
MIT licence (`LICENSE`, kept beside the files).

Only the six files `docs/Doxyfile` names are kept here, unchanged, from
**v2.4.1** (commit `1f3620084ff75734ed192101acf40e9dff01d848`). Until
2026-10-25 the whole repository was a submodule: 6.4 MB in every clone, 5.8 MB
of them the screenshots of its own documentation.

To update: download the release, copy the same six files over these, change
the version above, then `make docs-strict` and look at a page in light and
dark mode.
