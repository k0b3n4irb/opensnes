Detailed Description

The save: magic, version, checksum, and defaults when anything is off.

Record (8 bytes): 'S' 'D' | version | best (u16, little-endian) | wins | 0 | checksum of the seven bytes before. The record is flat bytes, never a struct dumped as is: no padding or endianness to depend on, and a layout change is a version bump.
