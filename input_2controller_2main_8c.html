Detailed Description

Both controllers on a terminal's test screen: buttons lit, the edges, a frame counter.

The pad test of a city terminal. The two controllers are drawn on screen, and each button held lights up on its pad's drawing, several at once; under each pad, the bitmask padHeld() returns, in hex. Under them, the last button pressed and the last button released on pad 1, and the number of VBlanks since boot. In the test bay at the bottom, each pad's D-pad walks its avatar: Kit for pad 1, the raccoon for pad 2. This is the starting point for understanding how SNES games read player input, and the screen the console check uses.

The SNES joypad has 12 buttons: 4 face buttons (A, B, X, Y), 2 shoulder buttons (L, R), a D-pad (4 directions), START, and SELECT. The NMI handler reads both joypads automatically every VBlank. Your code just calls padHeld(pad) for the buttons down, padPressed(pad) for the ones that went down on this frame, and padReleased(pad) for the ones that came up.

Ported from PVSnesLib "controller" example by alekmaul; the second pad was the two_players example, the counter the timer example, both merged here.

SNES Concepts
  • padHeld(n) — 16-bit bitmask of the buttons down on pad n (0 or 1)
  • padPressed(n) / padReleased(n) — the edges: down this frame, up this frame
  • KEY_A, KEY_B, KEY_X, KEY_Y, KEY_L, KEY_R, KEY_UP, KEY_DOWN, KEY_LEFT, KEY_RIGHT, KEY_START, KEY_SELECT — the bits, in the order the pad shifts them out (B Y SELECT START UP DOWN LEFT RIGHT A X L R)
  • frame_count — the VBlanks since boot, counted by the NMI handler
  • One lamp sprite per button, shown while its bit is set: the screen is a picture of the bitmask
What to Observe
  • Hold buttons on pad 1 or pad 2: they light up on that pad's drawing (cyan for pad 1, pink for pad 2) while held, several at once, and the HELD value under it shows their bits
  • The last button pressed and released on pad 1 stay on screen
  • Each D-pad walks its own avatar in the test bay
  • The counter goes up by 60 a second (50 on PAL); L+R together resets it
