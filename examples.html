OpenSNES Examples

The example corpus: small ROMs, each a folder with its main.c, its assets, a Makefile and a README.md that says what it shows. They go from a first line of text to playable demonstrations and three complete games.

  • In what order? Learning Path is the route through them, stage by stage.
  • Every example, by topic: Examples by Category is the full catalogue, one line each.

The table below counts them per folder.

Building

# Build all examples
cd opensnes
make
# Build a single example
make -C examples/text/print_string
# Clean and rebuild
make clean && make

Running

luna, the SDK's emulator (scripts/install-luna.sh installs it), plays any example in a window:

testing/bin/luna-gui examples/text/print_string/print_string.sfc

The headless luna dumps VRAM, OAM, palettes and registers (luna assets-dump, luna state) and is a full debugger over MCP: see Debugging. Any other SNES emulator works too.

Tips

  1. Read the source – every main.c is commented to explain the "why"
  2. Experiment – change values, break things, see what happens
  3. Look at the machine – luna assets-dump shows what the code put in VRAM, OAM and the palettes
