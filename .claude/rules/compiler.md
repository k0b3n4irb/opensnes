# Compiler Rules

## Architecture

Three git submodules:
- `cproc/` — C11 frontend, parses C into QBE IR
- `qbe/` — Code generator with custom 65816 backend, emits .asm
- `wla-dx/` — WLA-DX assembler (wla-65816) and linker (wlalink)

The `bin/cc65816` driver (a compiled program since 2026-10-06, `compiler/cc65816/cc65816.c`; a bash script before) orchestrates the pipeline:
```
.c → cc -E → cproc → QBE IR → qbe w65816 → .asm → wla-65816 → .obj
```

The qbe w65816 backend emits WLA-DX syntax directly (`.db`, `.dw`, `.SECTION`)
— the historical sed post-transform is gone.

## Build

```bash
make compiler       # Build all three submodules
```

This is a Class A change — requires `make clean && make` + full test suite (luna) on ALL examples.

## Critical Constraints

- **Bank $00 ROM is code only** (since #127.3, v0.41.0): C const data is placed in the asset banks and every C read of it is a far read; `devtools/check_bank_reads.py` fails the link on a bank-blind read. The bank $00 free-space ratchet still guards the code bank.
- **Plain C RAM lives below $2000; `FAR` is the way above it** (since chantier B2): `sta.l $0000,x` reads bank $00, so a plain global sits in `$00:0000-$1FFF`; `FAR` objects go to `$7E:2000-$FFFF` with bank-honouring codegen.
- **Refused, never miscompiled**: variadic functions, struct parameters / returns / assignment by value, inline assembly, floating-point values computed at run time, 64-bit integers (`long long`) computed at run time (both since 2026-10-08: they compiled to 16- and 32-bit integer code until then; constants the compiler folds, `(int)(1.5 * 256)` or `-2147483648`, are not refused). cc65816 stops with a message naming the feature; `devtools/compiler-tests/cases/negative/` pins the refusal, `KNOWN_LIMITATIONS.md` (Type & ABI gotchas) gives the workaround.
- **LEFT-TO-RIGHT argument push**: cc65816 pushes function args left-to-right, NOT right-to-left like tcc816/PVSnesLib.
- **`volatile` is honoured** (since chantier A2, 2026-05-09): cproc tags volatile loads/stores with a `volat` IR keyword that QBE's loadopt/promote/gcm passes respect. The SDK still favours plain globals for NMI handshake patterns for cycle-cost equivalence, but user code can use `volatile` for MMIO without silent coalescing.
- **`unsigned int` = 2 bytes, `unsigned long` = 4 bytes** on this target (since chantier A1, 2026-05-08).
- **The IR means what upstream QBE says, at this target's widths** (since 2026-10-08): `w` is 16 bits, `l` is 32, and `jnz` tests a word whatever the class of its argument — cproc compares a 4-byte condition with zero first (`cnel`) and the backend folds that compare back into the branch. A fork-only rule the optimizer does not know (the old "jnz tests both halves of an `l` temp") is a miscompilation waiting for a copy propagation; QBE's folder computes at `T.wordsz`, and so does the width inference of `copy.c` (`defwidthle`, since 2026-10-08: it sized shifts at 32 bits and dropped the mask of `(v >> 15) & 1`). Any `32`, `31`, `64` or `63` left in a generic pass is upstream's word, to be read again for this target before the pass is trusted. Six defects of this family were found in a day by `testing/difftest.py`. The same holds inside the backend: a Kw temp standing where a Kl operand is expected is zero-extended and owns ONE slot word — every read of a high half goes through `emit_load_high` / `emitop2_high`, never through `slot + 1` by hand.
- **Phi moves are a parallel copy** (since 2026-10-08): `emitphimoves` orders the moves of an edge and breaks a cycle through `tcc__r10`. Emitted in list order they miscompiled `prev = cur; cur += d;` in any loop. `QBE_DBG_PHI=1` lists them. The two ways out of a conditional branch do not share the A-cache: `branch_fork()` before the branch, `branch_join()` at the `+` label.
- **A submodule commit is staged in the superproject before any `make`**: the `submodules` target runs `git submodule update`, which puts a committed-but-unstaged submodule back on the old pin (detached HEAD) and the build then uses the old compiler. Uncommitted edits survive; commits do not until `git add compiler/<name>`. **And `git stash` / `git stash pop` undoes that staging** (2026-10-09): `pop` restores the working tree, not the index, unless `--index` is given, so the submodule pointer comes back unstaged and the next `make` checks the old pin out. A whole final validation ran on the previous compiler that way and was caught only by `verify-toolchain`. Do not stash on a branch that has a staged submodule; copy the files you want to compare instead.
- **A function has at most 2048 temporaries** (since 2026-10-08; 256 before, unchecked): `MAX_ALLOC_TEMPS` sizes every per-temp table of the backend, and `w65816_check_temps` stops the build beyond it. A guard of the form `if (idx < MAX)` that silently skips is a miscompilation in waiting: refuse instead.
- **Passes that change the CFG run before `gvn`, on plain SSA** (since 2026-10-08): `threadjnz` (`cfg.c`) lets each predecessor of a block that only chooses (one phi, the `jnz` on it) take the decision itself. After `gvn` one definition stands for every equal value wherever it was first met, so a block cut off there can hold the only definition of a value still used — `gcm` then asserts (`b0 != NOBID`). And `gvn` itself infers from the shape of the CFG: its phi-to-condition rule (`phicopyref`) trusted a phi argument whose edge it had just folded away, and returned `y != 0` for `(y || K) && 1`. A new shape reaching `gvn` gets a differential hunt of ten thousand programs, not two hundred.
- **An indexed addressing mode adds an UNSIGNED 16-bit index** (since 2026-10-08): `sym,x` and `[tcc__r9],y` carry into the bank byte, so they equal the 24-bit sum only for an index in 0..65535. `mark_far_decomp` keeps them for an index proven non-negative (`idx_nonneg`: a zero extension or a Kw temp, through non-negative constants) or straight off a symbol with no offset; `(far_arr + 8)[-1]` read bank $7F for a month. Any new use of X or Y as an index (stage S4 and after) asks the same question first.
- **A near `sym[index]` is a far access to the emitter** (since 2026-10-08): `mark_near_indexed` runs first in `emitfn` and `is_far()` answers yes for a load or store whose address is `$sym + index` (`sym_idx_form`), so the access takes the B2 path and its `lda.l sym,x`. Everything keyed on `is_far()` — the dead-store rule for stores, the address-only analysis, `far_decomp_all` — therefore applies to it unchanged; a field through a pointer (`NEAR_PTR`, `lda.l N,x`) and any other address in a temp (`NEAR_DEREF`, `lda.l $000000,x`) entered the same way the same day, except for an address a 32-bit load goes through (that load reads the full 24-bit pointer, `lda [tcc__r9]`, and keeps to). X is remembered between accesses (`x_load`, `x_keeps`): every instruction that is not itself an X-indexed access drops it, so a new instruction never has to declare that it writes X. `QBE_NO_NEAR_INDEXED=1` turns it off for an A/B.
- **`rep #$20` at function entry is kept wherever assembly could enter** (owner-level decision taken by the chief engineer on 2026-10-09, against item (b) of the plan): moving it to the caller for every function would have gained 3 cycles a call — under 1 % of the measured workloads — and added a silent failure, any assembly calling C in 8-bit mode. Only a function that is not exported and whose address is never used (`addrtaken()`, `main.c`: a data reference, or any code reference that is not a direct call's target) leaves it out. Anything that hands a C function to assembly does so through its address, so no new rule for hand-written assembly, and no lint, is needed.
- **The frame of a leaf function is in the direct page** (since 2026-10-09): `fn->leaf`, no alloc, at most 20 words (16 until 2026-11-13; `DPF_WORDS`, `QBE_LF_WORDS=N` uses fewer for a measurement) → temps at `tcc__lf` (`$0080`, 40 bytes, `templates/crt0.asm`), `framesize` 0. `SOFF(slot)` is the only way to turn a slot index into an operand and `emit_stack_load/store/op` the only places that print one: a new emit path that writes `(slot + 1) * 2` by hand puts a leaf's temp on the caller's stack. Three things hold it up, and each has a guard: a leaf calls nothing (the runtime helpers use `tcc__r0..r3`, `r9`, `r10`, not this block); the NMI handler's direct page mirrors the block (`tcc__nmi_registers`, 168 bytes — fixture `leaf_frame` runs the same leaf in the main loop and in the NMI callback); an IRQ handler is assembly. `$0040-$007F` is SNESMOD's, which is why the block is at `$80` and `.registers` must stay under `$40`.
- **A leaf too big for the direct page is split, not sent whole to the stack** (since 2026-11-04, `leaf_split` in `emit.c`): when a leaf with no alloc needs more than 20 words, `emitfn` restores the slots it had before colouring and colours it again with `leaf_split` set, which makes `color_slots` treat it as a function that calls with no `cross` temp: costliest first (`fn->tmp[].cost`, QBE's use count weighted by loop depth), first fit in `tcc__lf` (`DPSLOT + n`), the overflow on a stack frame. `dp_frame` stays 0 for it (its stack slots are real stack slots). Safe for the reason the all-in frame is. A leaf with an alloc or a dynamic alloc keeps the whole stack frame. `QBE_NO_LEAF_SPLIT=1` turns it off; check `leaf_split`, fixture `testing/fixtures/compiler/leaf_split` (values against a host model, and the main loop against the NMI). Known residue: a temp that gets a slot and is never emitted (a 32-bit index absorbed by `lda.l sym,x`) can be the only stack temp, and the frame is then reserved and unused.
- **A narrow 32-bit temp** (since 2026-10-09): a Kl temp whose high half nobody reads (`temp_addr_only`) and whose defining operation never reads back its own high half (`narrow_ok`: not a right shift, a divide, a call) takes one word of frame; `emit_store_high` returns at once for it. Every write of a high half therefore goes through `emit_store_high` — a direct `sta (slot+1)*2+2` on an instruction's result would land in the next temp's slot. Phi results are never narrow (the edge moves write both halves directly). A read of a narrow temp's high half is the high-half invariant's error.
- **A temp without a slot, and a function without a frame** (since 2026-10-08): the alias and dead-store analyses run BEFORE slot assignment and the temps they name get no slot (`temp_noslot`); reading one from the stack is an internal error, where a skipped store used to mean a silent read of whatever the slot held. Two things follow. An emit path that reads an operand's LOW half twice breaks the promise `consumes_r0_via_emitload()` makes (the Omul twin of the 2026-05-22 Oshl defect was still doing it): load once, keep the value in a direct-page scratch. And a function left with no slot has `framesize` 0, not the 2 bytes of alignment — parameters are read at `framesize + PARAM_OFFSET + n`, and a function with parameters, calls and nothing on the stack (`textInit`) read them 2 bytes too high for an afternoon. Parameter aliasing is `alias_opt` (every function); `leaf_opt` only gates going frameless and the skipped store before a return.
- **In a function that calls, a temp no call crosses lives in the direct page** (since 2026-10-10, `color_slots` in `emit.c`): the liveness walk that builds the interference graph also marks `cross[t]` for every temp live after an `Ocall` (its result apart; the operands of a Kl add inherit it, as they inherit interferences, because a folded add is read where it is used). A temp that is not `cross` is coloured first-fit in the 20 words of `tcc__lf` and gets slot number `DPSLOT + n`; the others, and the overflow, are coloured on the stack as before. `SOFF()` turns either into an operand, so nothing else in the emitter knows. Safe for the reason the leaf frame is: a callee may clobber the block, the value is dead by then; the NMI runs on its own direct page; the runtime helpers do not touch `tcc__lf`. A leaf that fits keeps the all-in direct-page frame; one that does not is coloured the same way since 2026-11-04 (`leaf_split`, below). `QBE_NO_DP_TEMPS=1` turns both off, and a compiler check that pins a STACK mechanism (phi moves between stack slots, offsets climbing during pushes, the large frame) sets it through an `env` line in its `.checks`.
- **A static function with one call site is inlined whole** (since 2026-10-10, `splice_fn` in `inline.c`): not exported, address not taken (`addrtaken`), exactly one direct call in the module → the caller's block is cut at the call, the callee's blocks are cloned between the halves with fresh temporaries, each parameter becomes its argument extended as the parameter's type says, each `ret` jumps to the second half (a phi when there are several), and the function is not emitted. `static inline` with several sites is copied at each, up to 160 IR instructions (`CC_INLINE_MAX_BIG`). The module is walked bottom-up (a callee's own calls are settled before it is cloned; a cycle is declined). Declined: an alloc left in the callee (a local whose address escapes), struct or variadic parameters, a caller near the 2048-temporary limit, and **a leaf above 16 IR instructions whose caller still calls something else** (`CC_INLINE_LEAF_MAX`; it would lose the `tcc__lf` frame and the peephole's direct-page rules; `mode7/extbg` booted four frames later). `QBE_NO_AUTO_INLINE=1` turns it off; `CC_TRACE_INLINE=1` names each absorption. Consequences to remember: a compiler check that needs a static function to STAY a function gives it two call sites; the benches' workloads are not static; `difftest_stmt.py` makes odd seeds `static` (4k+1) or `static inline` (4k+3), because with global functions no generated program reaches an inliner. **A copied block's label** is `inl<n>_<callee>.<index>.<block>`, the block part cut at 40 characters (`inl_label`); a cut that ends in `.b`, `.w` or `.l` (either case), which WLA-DX reads as an operand size, gets a trailing `_` (since 2026-11-14, I1 S1: three levels of copies failed the link on it). The back end refuses any function, block or object label of that shape (`wla_label_guard`, `qbe/emit.c`): an internal error for a block, a message to rename the file for a `static` of a source `b.c` / `w.c` / `l.c`, which linked to the wrong function before. `QBE_INLINE_FAULT=label` skips the repair, `QBE_LABEL_FAULT=noguard` the guard; fixture `inline_label_cut`, check `inl_cut`, refusals `negative/{b,w,l}`.
- **A peephole reads the emitted text before the branch pass** (since 2026-10-10, `peephole` in `emit.c`): inside a straight line of code it removes `sta S / lda S`, a store to S overwritten unread, a load overwritten by the next, and `lda S / tax` when X already holds S (S a frame slot: `tcc__lf+N` or `N,s`). Unlike the branch pass, a mistake here is SILENT — the assembler has nothing to refuse — so every rule is conservative by construction: a label, a branch, a call, `rep` / `sep`, `mvn` or anything not recognised ends the line; for a stack slot an access through a pointer or an index counts as a read and as a write, and anything that moves the stack pointer ends the line. Two things follow for the emitter: do not rely on a redundant load for its flags without a branch right after it (the reload rule keeps it only then), and a new instruction that writes X must be in `pp_writes_x`. Its proof is the differential hunt (10,000 seeds at introduction), not the corpus. **Two rules of this pass may each be right and wrong together** (2026-10-10): the rule that drops `cmp.w #0` relied on the load before it for N and Z, and the reload rule then dropped that load because the line after it was a store — the branch behind the store read a loop counter's flags, in one generated program of 100,000. A rule that removes an instruction for what ANOTHER instruction left (flags, a register) must be checked against every rule that can remove that other instruction; and `cmp` leaves the carry too, which a 32-bit unsigned compare reads two lines on (`cmp.w #0 / beq + / bcc ++`). A new rule gets a hunt of at least 20,000 program seeds before it is pushed. `QBE_NO_PEEPHOLE=1` turns it off.
- **A loop counter used only as one scaled index becomes that index** (since 2026-10-12, stage 2 T2, `ivar.c`, before `gcm`): `for (k = 0; k < N; k++) a[k] = v` runs on j = 2k — the header phi initialised to c·i0, stepping by c·step, tested by `cultw` against c·N, the products `extuh k · c` / `k · c` replaced by `extuh j` / j, the old add gone. Only when the init, the step and the bound are constants, the body is the header test's true branch, every other use of the counter is the same scale, the stepped value feeds the phi alone, and c·(N−1+step), c·i0, c·N fit 16 bits (nothing wraps). Nothing is created otherwise: a second counter in the direct page would cost more than the `asl` it saves; the point is a counter that IS the index, which T3 keeps in X. `QBE_NO_IVAR=1` turns it off, `-d V` traces it; checks `ivar_scaled_counter`, `ivar_off`, and `loop_bottom_test` / `index_once` pin the new shape.
- **X is known across the blocks of a function, and an indexed load is the operand of what it feeds** (since 2026-10-13, `peephole_xflow` and `peephole_fuse_indexed` in `emit.c`, text rules run once after the loop rule and before the entry one; the base pass runs again after them). `xflow` is a forward analysis over the function's text of the frame slot A equals and the frame slot X equals (`N,s` or `tcc__lf+N`, 16 bits), the state at a label being what every way in agrees on: a `tax` with X already equal to A's slot goes (with the `lda` before it when the next line loads A again), an `ldx` of the slot X already holds goes. X changes by a closed set of instructions (ldx, tax, tsx, tyx, plx, inx, dex, mvn, mvp, a call, plp, rep / sep of the index width); A by anything outside a list known not to; a slot's value by a write to it or to a byte of it, by a move of the stack pointer for a stack slot, by a call, and for a stack slot by a write through a pointer (`[..]`, `(..)`, `$0000,x`: a local whose address was taken lives on the stack) — a store indexed from a NAMED symbol writes a global and leaves the frame alone. `fuse_indexed`: `lda SYM,x / sta T / lda Y / [clc|sec] / op T` becomes `lda Y / [clc|sec] / op SYM,x` for cmp, adc, sbc, and, ora, eor (the operand's place is kept: a compare or a subtraction is not reversed) when T is a direct-page slot dead after the operation; since 2026-11-13 the same for a source that is an immediate, a frame slot (`tcc__lf+N` not sharing a byte with T, `N,s`) or a named symbol without index (`fuse_plain_src`: a numeric address, a possible I/O register, is refused), the `ldx` / `ldy` between staying in place (`QBE_NO_PEEP_FUSE_SRC=1`; checks `fuse_src`, `fuse_src_off`). `QBE_NO_PEEP_XFLOW=1`, `QBE_NO_PEEP_FUSE=1`; checks `x_across_blocks`, `fuse_indexed` and their `_off` twins, `peep_late`.
- **The counter of a rotated loop lives in X** (since 2026-10-12, stage 2 T3, `peephole_loop_x` in `emit.c`, a text rule run once after `peephole_late`): the entry test `lda S / cmp #N / bcs` becomes `ldx S / cpx #N / bcs`, the body's top `ldx S` (or `lda S / tax`) goes, a `lda S` in the body becomes `txa`, the step `lda S / clc / adc #c / sta S` becomes `inx` ×c (c ≤ 2) or `txa / clc / adc #c / tax`, the bottom test `cpx #N`. Only when nothing in the region writes X or the counter's slot (or its high byte), every read of the slot is a `lda.b`, there is no call or `mvn`, every label of the region is branched to from inside it, the slot is a direct-page one mentioned nowhere else in the function but the stores before the entry test (the counter dies with the loop — what ivar leaves), and the body's first touch of A before any branch is a write (A is not the counter at the body's label any more). It accepts the step anywhere in the region (gcm may order the accumulation after it) and the branch triples `bcc + / jmp @x / +` of that stage. `QBE_NO_PEEP_LOOPX=1` turns it off, `QBE_PEEP_LOOPX_TRACE=1` prints the text it reads; checks `loop_index_in_x` (a fill, a byte array, a stride of 8, a call in the body, the counter read after the loop) and `loop_index_in_x_off`.
- **A loop tests at its bottom, and a block's first load may go** (since 2026-10-11): `emitjmp` on a `jmp` to a block that is one compare and its `jnz` (`rotatable`) emits that compare and branch in place, with the edge moves of the copied block; `slot_owner_reset()` runs first, because the copy is read as at that block's entry. A compiler check that pins the moves on the way back to a condition sets `QBE_NO_ROTATE=1`. `peephole_entry` then drops `lda S` after a block label when every way in (the fall from above and each `jmp @label`; any other mention of the label refuses) comes straight from `lda S` or `sta S` through compares and conditional branches only. It removes an instruction another rule may have counted on for N and Z, so it runs LAST and once, and keeps the load unless an instruction that sets the flags comes before anything that reads them. A rule added after it in `relax_branches` must not assume a block starts with a load. `QBE_NO_PEEP_ENTRY=1`.
- **A function is emitted into a temporary file and read back** (since 2026-10-09, `relax_branches`): the triple `bxx + / jmp @target / +` that `emitjmp` writes becomes `byy @target` when an UPPER BOUND of the bytes in between (`line_bytes`: the width suffix, else the operand's shape, 4 when unknown) is within 124. A shortened branch stays in the line array as a line of its own: dropped from it (first version), its two bytes were missing from every later backward bound, and one program in 4,000 of the hunt failed to link at 129 bytes. Two consequences for whoever touches the emitter: a new instruction form must be boundable by `line_bytes` or it counts 4, and a line that carries both an anonymous label and an instruction (`+<tab>lda.w #1`) is an instruction — the first version skipped it and judged a 129-byte branch near. The assembler refuses a branch out of reach, so a wrong bound fails the link; it does not miscompile. `QBE_NO_SHORT_BRANCH=1` turns the pass off.
- **Compare and branch fuse only when adjacent** (since 2026-10-08): `gcm` orders a block by dependencies, so `cmplast` (`cfg.c`, skiprega targets) moves the compare a block branches on to its end. Fused forms: every 16-bit compare, a signed compare against 0 (N of the load), `cnel x, 0` and 32-bit `ceql` / `cnel` (two compares and a skip, label `@lcmp.N`). The other 32-bit compares still materialise 0 or 1.
- **No register allocator means no dead-code sweep for free** (since 2026-10-08): upstream QBE lets spill/rega drop a definition nobody uses, and this target skips both (`T.skiprega`). `gcm.c` therefore sweeps after `sink()` (`sweepdead`). A new middle-end transformation that can leave a definition without a use must be followed by that sweep, or the emitter will emit it — it has no "result unused" rule of its own.
- **A pinned instruction is folded only if it is an integer div / rem** (since 2026-11-07, `dedupins` in `gvn.c`): `pinned()` keeps gcm from moving a div / rem (it may trap), and `dedupins` used to return on it before `foldref`, so `19391 / 3584` called `__sdiv16`. It now tries `foldref` on `isdivwl` instructions alone (no `copyref`, no value numbering); `foldint` refuses a zero divisor and INT_MIN / -1 at the class width, which stay calls. Not done: `x / 1`, `0 / x`, and a signed divide by a power of two (`n / 8` with `int n` calls `__sdiv16`; the unsigned one is a shift, `simpl`). Check `const_div_fold`, fixture `testing/fixtures/compiler/const_div`.

- **A one-word copy may share its source's slot** (since 2026-10-31, `word_copy`, `color_slots`): `extuh` / `extsh` / `extuw` / `extsw` of a Kw temp into a Kw or a narrow Kl temp adds no interference with its source, and the source is coloured first. Same value, two names: `copy_root` is what makes the slot-ownership check accept it. SSA is the proof: neither is written again while both live, and the move that writes a phi source sits on an edge its copy, defined after the phi, cannot be live across. `QBE_NO_COPY_SHARE=1`.
- **A load goes down to the one way out that needs it** (since 2026-10-31, `sinkload` in `cfg.c`, after `cmplast`): not volatile, nothing with an effect after it in its block, every use dominated by a successor whose only predecessor is this block, none in a phi. Its address goes with it when nothing else reads it. It never leaves a loop's body for a deeper one: such a successor would be a header with two predecessors. `QBE_NO_SINK_LOAD=1`.
- **A direct-page store nothing reads again goes** (since 2026-10-31, `peephole_slotdead`): `pp_slot_live_at` over the function's text, after the group of `fuse_indexed` and again after `peephole_entry`, whose removed loads are often a slot's last reads. A store sets no flag, so nothing around it can depend on it. It refuses a function that names `tcc__lf` in any form other than the plain operand, and a store a word access at the byte below overlaps. `QBE_NO_PEEP_SLOTDEAD=1`; a check that pins the stores themselves sets it. `pp_a_is_slot_before` walks through `ldx` since the same day, and `peephole` drops `lda S / sta S` and the `lda S` of `sta S / ldx P / lda S`.
- **A byte read is a word read and a mask** (since 2026-11-11, A6a R1, `byte_load_as_word` in `emit.c`): `lda <operand> / and.w #$00FF` with a 16-bit accumulator, not `sep #$20 / lda / rep #$20 / and`. The byte above is read too: harmless on RAM and ROM, a second read on a register with a read side effect. Decided where the load is emitted, from the IR: never for a `volat` access; yes for a named symbol, a frame slot, a stack local, a pointer known only at run time; for an address with a compile-time constant part only when that constant is below `$2000` or in banks `$7E-$7F` (`*(u8 *)0x2138` and `((u8 *)0x4210)[i]` stay 8-bit). The SDK reads every register through a volatile lvalue (`REG_*`); a register address reaching a plain pointer at run time is the documented limit (`KNOWN_LIMITATIONS.md`, `ABI.md`). The pair also ended the text rules' straight lines: removing it let `peephole_r9_loop` keep a far pointer in `tcc__r9` across loops whose body reads a byte through it. `QBE_NO_BYTE_WORD=1`; checks `byte_word`, `byte_word_off`.
- **The counter of a rotated loop lives in Y when X is taken** (since 2026-11-11, A6a R2, second pass of `peephole_loop_x`): when the region writes X (a table lookup through `tax`, a second index), the same rewrite with `ldy` / `cpy` / `tya` / `iny`, provided nothing in the region writes Y (ldy, tay, txy, ply, iny, dey, phy, plp, rti, mvn, mvp, a call, rep / sep of the index width) but the counter's own reads. Both passes also read `lda.b S / t<reg>` (the pair goes when A and N/Z are dead after it, else `t<reg>a`), `lda.b S / t<other>` (`t<reg><other>` when A is dead after, 16-bit accumulator only: with 8 bits the transfer copies the hidden byte; `pp_a16_at`), `ld<reg>.b S` (goes when N/Z are dead after it, `pp_nz_dead_after`), `ld<other>.b S` (`t<reg><other>`) and `lda P / clc / adc.b S` or `lda P / and|ora|eor.b S` (`t<reg>a / clc / adc P`, `pp_alu_of_slot`: the operation commutes). So `lda.b S / tay / lda [tcc__r9],y` is `lda [tcc__r9],y`, the far-frame and FAR_BASE_IDX accesses whose Y IS the counter. A loop converted to one register may contain or surround one converted to the other. `QBE_NO_PEEP_LOOPY=1` turns the Y pass and the new reads off; checks `loop_index_in_y`, `loop_index_in_y_off`.
- **A load of what A already holds goes, across blocks** (since 2026-11-11, A6a R3, `peephole_xflow`): the A half of the analysis, which only fed the `tax` rule, now removes `lda S` when A equals S on every way in and N and Z are dead after the load (`pp_nz_dead_after`: stores and flag-neutral lines pass, a line that sets N and Z without reading them ends the walk, a block label is walked through on the fall-through, anything else keeps the load). A fill's body is `sta.l buf,x` alone. In a function that stages `tcc__r9`, a load right after a label stays: `peephole_r9_loop` needs a loop whose first line writes A, and is worth more. The analysis now also forgets everything at `mvn` / `mvp` (they write memory) and `tcd` / `pld` (the direct page moves). The base pass's `sta S / ldx P / lda S` rule takes `ldy`, `tyx` and `txy` in the middle too, and accepts a block label after the stores when N/Z are dead (`k_col_c`'s `sta S / ldx P / lda S / sta.w colbuf,x / @for_cont:` kept its load because only the plain reload rule knew labels). Two rules right and wrong together: this one removes a load for what earlier lines left in A, and every rule run after it reads the text as it is (`r9_loop`, `peephole_entry`, `forward_store`, `dec_loop` each check the line they need is there). `QBE_NO_PEEP_AFLOW=1` turns both parts off; checks `a_across_blocks`, `a_across_blocks_off`; checks that pin an older shape set it (`per_object_loop_off`, `test_phi_dichotomy`, `test_ssa_loop_complex`).
- **A constant added to a loop counter goes into the symbol** (since 2026-11-11, A6a R4, `testbound` in `reassoc.c`): `reassoc` folded `sym[x + k]` into `sym+k*s` indexed by x only when x's own definition bounded it (`extub`, `and`, `shr`); a loop counter is a phi. It now also takes the bound from a test that dominates the add: a block ending in `jnz` on `cultw x, N` (`culew`), whose true successor is entered from it alone and dominates the add, gives x <= N - 1 (N), and x + k <= 0x7FFF makes the fold exact (no 16-bit wrap, no negative index for `sym+K,x`). Nothing is inferred from an access being out of bounds. The old `add x, k` is now nopped when the extension was its only use (left for gcm, it was still a use of the counter when `ivar` looked, and the counter was not rewritten). `k_fillu_c` (the fill unrolled by hand) becomes one `tax` and eight `sta.l fl_buf+2k,x`, its counter scaled by `ivar` and kept in X. `QBE_NO_REASSOC_LOOP=1`; checks `reassoc_loop`, `reassoc_loop_off`.
- **Two masks in a row are one** (since 2026-11-11, A6a R5, `peephole`): `and.w #K1 / and.w #K2` (adjacent, both numeric) becomes `and.w #(K1 & K2)`: A, N and Z come out the same. A byte read and its zero extension each masked the value (`and.w #$00FF` twice), and a bit test of a byte became `and.w #$00FF / and.w #8`. `QBE_NO_PEEP_AND2=1`; checks `and_and`, `and_and_off`.
- **A dense `switch` is a jump table, emitted from the compare tree** (since 2026-11-12, L2, `jt_find` / `emit_jt` / `jt_rewrite` in `emit.c`): the tree cproc builds stays in the IR (a QBE block has two successors); before the blocks are emitted, a region of blocks that only compare ONE Kw temporary with constants and branch (the root ends on such a compare, the members are entered from the region alone, have no phi and hold nothing but the compare and its jnz, or are an empty jump to a block without phi) is evaluated on all 65 536 values: the default is the exit most values reach, the window `[MIN, MIN+RANGE)` the smallest cyclic one holding the others, so the table equals the tree for every value by construction. `lda v / [sec / sbc.w #MIN] / cmp.w #RANGE / bcc + / jmp @default / + / asl a / tax / jmp (@jtt.N,x)`, the table `.dw` before the function's `.ENDS` (same section, read through the program bank; HiROM, FastROM, SA-1 and `__ramcode` checked), the members not emitted (`jt_role`, `b->link` skips them, `rotatable` refuses a root). An exit whose edges carry phi moves is reached through a stub `@jts.N.k: <moves> / jmp`; edges of the region into one exit with different moves, a phi reading a compare of the region, an edge back to the root: the tree stays. A refused region's subtrees are tried as roots, so a dense cluster of a sparse switch becomes a table of its own. Taken from 4 values off the default and 4 compares in the region (`JT_MIN_CASES`) and a window of at most 3 slots a compare (`JT_DENSITY`, 1024 slots at most): the tree's size is its compares, the table's its slots; measured on luna, the table wins in cycles from 2 cases and in bytes up to a stride of 6 between cases (two compares a case there), and X, which it takes, costs a `tyx` a case to a loop whose counter it pushes into Y. The first version counted values, not compares, and made a table of 96 slots of one target out of `c >= 32 && c < 128` (a range test is two compares: refused now, check `jump_table_tree`). **The text passes never see the jump**: while they run, the dispatch is `asl a / tax / bvs @t1 / ... / jmp @tk`, one branch per distinct target — every pass then reads the right successors and the state at each target (the state at the `tax`), nothing falls through, and no pass reads a `bvs` for its condition; `jt_rewrite` (in `relax_branches`, before any distance is bounded) finds that group line for line and writes `jmp (@jtt.N,x)` in place of the branches. A pass that changed the group (the `tax` the jump reads and no branch shows) is an internal compiler error, not a jump through a stale X; a new pass must leave a `bvs` alone. The table is printed after the passes: no pass sees a data line. `QBE_NO_JUMP_TABLE=1` turns it off, `QBE_JT_TRACE=1` says per region taken or refused and why (`QBE_JT_MIN_CASES`, `QBE_JT_DENSITY` override the thresholds for a measurement); checks `jump_table`, `jump_table_off`, `jump_table_tree`, fixture `testing/fixtures/compiler/jump_table` (values against a host model, main loop against NMI); checks that pin the tree set the switch (`switch_dense_leaf`).
- **Every `.c.asm` carries the static-frame side table** (since 2026-11-14, L4 S1, `sframe_dump` in `emit.c`, comments after each function's `.ENDS`: `; sframe fn` with `sf=` the bytes of its static frame, `; sframe call` per IR call, `; sframe addr` and `; sframe table 1` at the end of the unit). `opensnes-rom place` builds the program's call graph from it; `opensnes-rom check --objects` derives the same graph from the instruction lines and refuses the link when they differ (`devtools/sframe/test_sframe_link.py`, in `make tests`). A new way of emitting a call (a helper, a tail call, a call through a pointer) is therefore a table line too, or a name in the tool's `HELPERS`; `QBE_SFRAME_FAULT=noedge` is the provoked fault.
- **A counter or an index lives in X or Y for its whole life when its emission proves it** (since 2026-11-14, lot XY, `color_slots` / `xy_emit` in `emit.c`; the G1 probe's note `.claude/notes/chantiers/gap_lots/G1_ir_probe.md`): a web of 16-bit temps (a phi and its arguments, a one-word copy and its source, joined only when no two of them live together) with an index use or a loop-carried phi, never live across a call, is given X or Y instead of its slot: defined by `tax` / `tay` (`inx` / `dex` for a step of 1 or 2, `ldx #k` for a constant phi move), read by `txa` / `tya`, compared with `cpx` / `cpy #k`, an index for nothing in X or as `sym,y` in Y (a plain object only: there is no `long,y`). **The emission is the proof**: while a function is emitted with the colour, each candidate's slot number is `XYSLOT + k`, so any emit path that still reaches the slot (an ALU operand, a high half, a phi cycle) refuses it in `SOFF()`; each IR instruction's text is read back and a write of the register that is not the colour's own while a value of it lives after or is read refuses that value, as does the colour's own write over another live value of the same register (the probe's first version trusted the interference graph there and wrote `i = 2; while (i--)` as 0), a store with an 8-bit accumulator, a `tax` whose N / Z something reads, and `sym,y` on a form without abs,y; the function is emitted again until nothing is refused. **The loop rule** (`peephole_loop_x`) is told where a coloured value of each register lives (byte ranges of the accepted text) and converts a loop to that register only where none does (`QBE_XY_FAULT=3` blinds it: `difftest_stmt` seed 961160 fails); a plain emission run through the passes up to the loop rule first says which counters the rule takes: a web on such a counter gets the rule's register first, a web beside a rule counter the colour left in memory does not take that register, and a lighter web beside a rule counter the colour refused (an ALU operand: `tya / ora S` has no form with S in X) takes none. A function where nothing is coloured is emitted exactly as without the colour. `QBE_NO_XY_COLOUR=1` turns it off (byte-identical output), `QBE_XY_TRACE=1` lists the candidates, the attempts and why each refusal, `QBE_XY_ASSERT=1` is the assertion build (every coloured value also stored in its slot at its definition and compared with the register at each use, `stp` on a difference: the check that does not rest on the interference graph), `QBE_XY_FAULT=1|2|3` the provoked faults (a `tax` too many the proof trusts or not; the loop rule blind). Checks `xy_colour`, `xy_colour_off`; the checks that pin the text rules' own shapes set the switch.
- **A far pointer is read in its slot, and stepped on 16 bits when one object of this unit is all it can point into** (since 2026-11-14, lot E1, `farptr_web` / `farptr_step` and `peephole_dp_ptr` in `emit.c`; `.claude/notes/chantiers/gap_lots/E1_far_pointer.md`). Two parts. **The text rule**, run LAST in `relax_branches`: a staging `lda.b tcc__lf+N / sta.b tcc__r9 / lda.b tcc__lf+N+2 / sta.b tcc__r9+2` goes and the `[tcc__r9]` / `[tcc__r9],y` accesses of the straight line after it read `[tcc__lf+N]`, when nothing on that line writes bytes N-1..N+3, moves the direct page or calls, tcc__r9 is dead where the line ends (`pp_r9_live`, a call counted as a read) and the first line after the staging writes A without reading it; `sta.b S / (staging) / lda.b S` loses its load too. Every earlier text rule takes a direct-page slot for unreachable through a pointer (`pp_slot_live_at` says so): a rule added after this one must read `[tcc__lf+N]` as a read of three bytes. **The step**: a C object never crosses a bank (its own section in one bank's slot; the linker refuses one that does not fit, measured), so a Kl temp computed from the address of an object DEFINED in this unit (`datdef_has`, `main.c`) by copies, phis and `add` / `sub` of integers, and used ONLY as an access's address or to compute another such temp, is kept as (low word, the root's bank): its `add` / `sub` computes the low word and copies the bank word, or writes nothing when result and operand share a slot. Not for a pointer from a parameter, a call, memory, an `extern` object (assembly may put one across `$7E:FFFF`), nor for one compared, tested, stored, passed or returned: an object may END at `$xx:FFFF` (measured, `$7E:FFF0-$FFFF`), and its one-past-the-end pointer, valid to compare, would read `$7E:0000`. An access outside the object (undefined) that crosses a bank wraps inside it. Also found: a pointer compared with the CONSTANT `obj + size` of such an object stops the link ("out of 16-bit range"), a loud limit older than the lot. `QBE_NO_FARPTR_DP=1` turns both parts off (byte-identical output), `QBE_FARPTR_TRACE=1` names the members, `QBE_FARPTR_FAULT=1|2|3|4` the provoked faults (an extern taken for a root, the use rule skipped: fixture `testing/fixtures/compiler/farptr_dp` fails; the text rule blind to a live tcc__r9: `difftest_stmt` fails 22 seeds of 30; blind to a write of the slot: no emitted text has that shape today, the output does not change). Checks `farptr_dp`, `farptr_dp_off`.

## After Any Compiler Change

1. `make clean && make` — full rebuild (stale objects cause phantom bugs)
2. `make tests` — luna coverage + visual regression + probes
3. Present the triaged representative examples to the user (luna visual
   pass is the reference; interactive spot-check via `luna mcp` / luna GUI
   if needed — see docs/tutorials/debugging.md)
4. Check for regressions in code generation with compiler test patterns
5. `python3 testing/difftest.py --seeds 1-2000` and `python3 testing/difftest_stmt.py --seeds 1-2000` — the two differential tests beyond their gates (about a minute each)

## Width literals in cproc are ratcheted (since 2026-10-05)

`make lint-cproc-widths` (in `make lint`) lists every `'w'` / `'l'` /
`ILOADW` / `ISTOREW` / `ILOADL` / `ISTOREL` outside `qbetype()` in
`compiler/cproc/qbe.c` and fails on one that is not in
`devtools/cproc_width_sites.txt`. Those sites are where upstream's model
(`l` = 8 bytes) survives unless re-read for this target (`int` 2, `long`
4, pointer 4): `funccopy`'s chunk table, `zero()`, the bit-field
extraction and the cast scaling were each found by a consumer, one at a
time (compiler audit 2026-10-03, PF3). A new site is reviewed, then added
with `--update`; `testing/fixtures/compiler/d_quals` is where its
runtime effect gets a cell.
