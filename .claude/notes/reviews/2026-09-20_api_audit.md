## 1. What matters

1. **The ABI layer is sound; the bank byte is not.** Every hand-written ASM
   function with a return value leaves it in A (after the `objCollidObj` fix),
   and stack offsets match the post-A6 slots with two exceptions (§2, B9 B10).
   But **seven functions receive a far pointer and throw its bank byte away**
   (B1 B3 B4 B5 B8 B12, and `OAM_SET_GFX`). Since v0.41.0 the SDK *places
   const data outside bank `$00` by default*, so each of these reads garbage
   from the data layout the project itself recommends. The examples work only
   where a SUPERFREE section happened to land in bank `$00`. This is one class
   of defect and should be fixed as one chantier, with a test per function that
   puts its data in `ASSET_SECTION`.
2. **Symmetric test inputs hid three argument bugs** (B9 B10 B11): a fade whose
   target is always 0 was tested with target 0; two swapped arguments were
   called with `(40, 40)`; an ignored colour index was called with index 0.
   The ABI lint missed the first two because their stack comments do not name
   the parameter. Rule for new vectors: **never pass equal or zero values for
   distinct parameters.**
3. **Pre-A6 residue is the main breaking-change theme**: four `*Bank`
   functions, `dmaTransfer`'s split bank/address, `hdmaSetupBank`,
   `OAM_SET_GFX_BANK`. Pointers carry their bank now; these exist only because
   they once did not.
4. **Naming and truth values are inconsistent across families**: six naming
   schemes in `console.h`, "Held" meaning two things in `input.h`, `Enable`
   meaning *replace* in two modules and *accumulate* in two others,
   `hdmaEnable` taking a mask where its siblings take an index (and the
   header's own examples passing an index), booleans returned as `0xFF`, `1`
   or a raw flag.
5. **Documentation rot is the largest class by count** (~60 of ~140). The
   worst cluster describes designs that no longer exist: the VBlank handshake
   (`system.h`, `interrupt.h`), the HDMA "repeat mode required" doctrine that
   `.claude/rules/hardware_claims.md` retracts, `window.h`'s polarity and a
   function that does not exist, `anim.h`'s bank-`$00` warning, `math.h`'s
   "the compiler's multiplication has bugs".

## 3. Breaking changes to decide before the freeze

Grouped by theme. Each is a *proposal*; none is applied.

### 3.1 Remove the pre-A6 "bank" residue

| Today | Proposed |
|---|---|
| `nmiSet` + `nmiSetBank`, `irqSet` + `irqSetBank` | one function each, typed `void (*)(void)`, bank from the pointer (fix B2); drop or internalise `*Bank` |
| `dmaCopyVram` + `dmaCopyVramBank`, `dmaCopyCGram` + `dmaCopyCGramBank` | drop the `*Bank` forms |
| `dmaTransfer(ch, mode, srcBank, srcAddr, destReg, size)` | `dmaTransfer(ch, mode, const u8 *src, destReg, size)` |
| `hdmaSetup` + `hdmaSetupBank(table, bank)` (carries two banks; the explicit one wins) | drop `hdmaSetupBank` |
| `OAM_SET_GFX` (bank 0) + `OAM_SET_GFX_BANK` | one `oamDynamicSetGfx(id, const u8 *gfx)` taking the bank from the pointer (fixes B8) |

### 3.2 One meaning per word

| Today | Proposed |
|---|---|
| `hdmaEnable(mask)` while every other hdma function takes a channel index; header examples pass the index | `hdmaEnable(u8 channel)` + `hdmaEnableMask(u8 mask)` (or keep the mask and add `HDMA_MASK(ch)`), and fix the header examples either way |
| `colorMathEnable` / `mosaicEnable` **replace** the layer set; `windowEnable` / `hdmaEnable` **OR** into it | rename the replacing ones `…SetLayers`, or make all additive with a matching `Disable(mask)` |
| `padHeld` / `mouseButtonsHeld` = currently down; `scopeButtonsHeld` = auto-repeat, currently-down is `scopeButtonsDown` | one verb set (Held / Pressed / Released) on pad, mouse and scope; rename the repeat one |
| objects: `objKill` / `objGetPointer` take a **handle**; `objCollidMap`, `objCollidMapWithSlopes`, `objCollidMap1D`, `objUpdateXY`, `objCollidObj` take an **index**, under a parameter named `objhandle` | add `and #$00FF` to the five index routines so both work, and name the parameters truthfully |
| predicates return `0xFF` (`isPAL`, `isInVBlank`, `padIsConnected`), `1` (`getRegion`, `mouse*`), or a raw flag (`scopeIsConnected`); `TRUE` is `0xFF` | `bool` from every predicate; `TRUE` = 1 or deprecated |
| `sa1Init()` initialises nothing (crt0 does) — it is a status getter; docs elsewhere cite a `sa1IsReady()` that does not exist. `dsp1Present` (u16), `gsuInit` (u8, also sets defaults) | `sa1IsReady` / `dsp1IsPresent` / `gsuIsPresent`, all `bool` |

### 3.3 Names that will be regretted once frozen

- `console.h` hosts six schemes: `console*`, `setScreen*` / `setBrightness`,
  `fade*`, `WaitForVBlank` (the lone PascalCase), `is*` / `get*` / `reset*`,
  and libc's `rand` / `srand` with non-libc signatures. At minimum: rename
  `rand` / `srand`; decide `WaitForVBlank` vs `waitForVBlank`.
- `consoleMesenBreakpoint` / `consoleNocashMessage` live in `debug.h` under the
  `console` prefix (the header itself says "kept for source compatibility") —
  the `SNES_BREAK` / `SNES_NOCASH` macros can absorb a rename.
- `LzssDecodeVram` is the only capitalised public function.
- `sqrt16`, `atan2_8`, `ease_in_quad`, `ease_out_quad`, `mul16` break the
  `fixXxx` camelCase of every sibling.
- `gfxLoad` / `bgLoad` belong to the `asset` module but squat the `bg`
  namespace; `gameLoopRun` + `GameLoopConfig` duplicate `sceneRun` + `Scene`.
- `t_objs` is the last PVSnesLib-style type name; positions are `u8 xpos[3]`,
  so every user writes `xpos[1] | (xpos[2] << 8)`. Accessors cost nothing now.
- Unprefixed exported globals become frozen API: `x_pos`, `y_pos` (camera),
  `cursor_x`, `cursor_y` (text — `input.h`'s own example uses a user variable
  with that name), `cgwsel`, `cgadsub`, `mosaic_size`, `objptr`, `objgetid`.
- Duplicates to prune: `getRegion` vs `isPAL`; `profileGetFrameCount` vs
  `getFrameCount`; `VBlankCallback` vs `VoidFn`; `BG_MODEn` vs
  `BGMODE_MODEn`; `mode7SetPivot(u8,u8)` vs `mode7SetCenter(s16,s16)`;
  `mul16` / `div16` / `mod16` vs the C operators; four identical layer-mask
  constant sets.

### 3.4 Types and const

- `collision.h`: read-only `Rect *` parameters are not `const`. On this target
  that is a silent failure, not style: a `static const Rect` is in an asset
  bank and only const-qualified loads are far reads.
- `asset.h`: `GfxAsset` / `BgAsset` fields and the `DECLARE_*_ASSET` externs
  are non-const `u8 *` onto ROM data — same trap.
- `sprite.h`: `oamSet(u16 id…)`, `oamSetX(u8 id…)`, `oamSetY(u8 id, u8 y)`,
  `oamDrawMeta(s16 x, s16 y)` — one id type, one coordinate type.
- `fixLerp(a, b, u8 t)` documents `t` as 0-256; make it `u16` (same stack
  slot, no ABI change) so 1.0 is reachable.
- `dsp1Multiply(u16, u16)` etc. carry signed 1.15 values as `u16`.
- `mapLoad(const u8*, const u8*, const u8*)` takes three interchangeable
  blobs; `objLoadObjects(const u8 *)` takes a table of `u16` quintuples with a
  magic `0xFFFF` terminator.

### 3.5 Functions that cannot report what they must

`scenePush` / `scenePop` fail silently (full stack; depth 1 — and the
documented swap idiom cannot replace the bottom scene, so a title→game→title
cycle leaks a slot per lap); `objGetPointer` reports failure only through a
global; the whole `sram` family and `audioInit` return `void`; the audio
setters swallow `AUDIO_ERR_*`; `audioPlaySample*` returns a bare `0xFF`;
`audioPlaySampleEx` has no voice parameter although `AUDIO_VOICE_AUTO` is
defined and unused, so `audioSetADSR(voice, …)` cannot be aimed.
Returning `bool` / an error code is free now and impossible later.

### 3.6 Dead or unreachable API — remove or finish

- `snesmodSetSoundTable` / `snesmodAllocateSoundRegion`: nothing ever sets
  `digi_active`; there is no port of the streaming play call. (The fixture
  covers them; it cannot make them useful.)
- `gsuSetProgram` is documented as a prerequisite of `gsuLaunch` and exists
  only in an example's assembly file.
- `windowSetMask` is used in `window.h`'s own example and does not exist;
  four `WINDOW_*` constants have no user.
- `audioUpdate` (no-op), the three legacy `audio*` macros (one expands to
  nothing), `consoleInitEx` (ignores its argument), `padRaw` (not raw),
  `oamUpdate` (redundant with the NMI, corrupts OAM outside VBlank).
- `sramClear(size)` cannot clear one slot; `sramChecksum` is an 8-bit XOR that
  validates a freshly cleared save.

### 3.7 Compile-time introspection

No numeric version, no `OPENSNES_VERSION_AT_LEAST`, version macros only in the
master header, and `HIROM` / `SA1` / `FASTROM` / `SUPERFX` / `DSP1` reach the
assembler but not C. Additive, but worth having *at* 1.0.

## 4. Documentation fixes (no decision needed)

Wrong in a way that misleads: `system.h` `vblank_flag` protocol is backwards
and `oam_update_flag` is not set by `WaitForVBlank`; `interrupt.h` `nmiSet`
timing (skipped on lag frames, runs *after* OAM/tilemap/scroll, needs warnings:
no `WaitForVBlank`, no `$2180-$2183`, no channel-0 DMA); stale "must be in bank
0" note on `nmiSet`; `setScreenOn` "full brightness"; `consoleInit` claims three
things it does not do; `WaitForVBlank` hangs with NMI off; `fadeOut(speed 0)`;
`rand` never returns 0; pad functions accept 0-4, not 0-3.
`hdma.h`: the repeat-mode doctrine; channel 7 recommended in seven places
against the header's own warning; `hdmaWaveInit` disables every channel;
helpers auto-enable inconsistently. `window.h`: inverted polarity text.
`colormath.h`: the overview setup contradicts the working example.
`background.h`: alignments mix bytes and words; scroll is deferred to the NMI
and `bg > 3` overruns. `sprite.h`: stale performance folklore, a dead `@see`
path, `oamDrawMeta`'s `@return` (the Flip variant was fixed, this one not).
`math.h` / `fixed32.h`: `UNFIX` floors, not truncates; `fixSqrt` has 4
fractional bits, not 5; the angle convention of `atan2_8` contradicts the
`fixSin` / `fixCos` movement examples (90° off); "the compiler's multiplication
has bugs"; `fix32Mul/Div/Lerp` lack `fixMul`'s NMI warning; `fixSin`'s Doxygen
block documents the table instead. `anim.h`: the bank-`$00` warning is stale
since #127.3 and its mitigation now wastes RAM. `text.h`: 2048 bytes of the
8 KB band, unstated; `tilemapBuffer` undeclared. `scene.h`: `init` runs on
every push, deferred, not "on the first push". `panel.h`: `panelFlush` always
un-blanks. `map.h`: `mapSetMapOptions` must follow `mapLoad`, which also zeroes
the camera. `snesmod.h`: quick start passes a pointer to a function taking a
bank; effects must be reloaded after every module load; "main loop or NMI" is
unsafe; `snesmodInit` forces `$4200 = $81`. `audio.h`: echo max is 7 not 15;
"unload stops voices" is not implemented; "every wait is bounded" is not true
of `audioInit`. `lzss.h`: `sei` masks IRQ, not NMI. `dsp1.h`: the file-level
Rotate example still says (0, 100). ASM comments the lint cannot see: `sram.asm`
"right-to-left push" and 2-byte pointer maps, `compiler/ABI.md:52` vs its own
line 355.

## 5. Recommended order

1. **The bank-byte chantier** (B1 B2 B3 B5 B8, and `hdmaSetupBank` /
   `dmaTransfer` once decided): one class, one test pattern — data in
   `ASSET_SECTION`, assert the effect. This is the only group that silently
   breaks users who follow the project's own placement advice.
2. **The argument bugs** B9 B10 B11 B13, with asymmetric non-zero vectors.
3. **The rest of §2**, smallest first (B7 B14 B15 B16 B17 B18 B19 B20; B6 and
   B12 need a design choice; B4 needs a decision on HiROM/SA-1 SRAM).
4. **§4 documentation**, which needs no decision and removes the text most
   likely to mislead a new user.
5. **§3 decisions**, theme by theme, then one breaking-change release (0.44 or
   0.50) that applies them with deprecated aliases where cheap — and only then
   the 1.0 freeze.

## 6. Corrections to my own earlier notes

`.claude/notes/status/api_audit_findings.md` said "`nmiSet(callback)`
dispatches in bank `$00`". **Wrong**: `nmiSet` derives the bank from the far
pointer (`console.c:268-274`); only the header's "must be in bank 0" note is
stale. The function with that defect is `irqSet` (B2). The same wrong claim is
in a comment of `devtools/libtests/main.c` and `devtools/libtests_fx/main.c`
and in two commit messages (bc87cb44, 3e77510e — history, not editable).
